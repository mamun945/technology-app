###Name of your project

TechStacker

###A little description

Dev Stack is a developer-focused platform that provides curated technologies, tools, and resources to help developers discover and explore modern software technologies in one place.

###Technology that you use
React.js
TypeScript
Tailwind CSS
React Icons
Vite

###3 Features about your project

1. Technology Collection
Developers can explore different technologies with useful information such as technology name, category, badge, rating, and other details.

2. Add to Stack
Users can select their favorite technologies and add them to their personal stack for easy access.

3. Responsive Design
The website is fully responsive and works smoothly across mobile, tablet, and desktop devices.

5. Why does every item in a .map() list need a unique key prop?

Answer:
When React renders multiple elements using map(), each element needs a unique key so that React can **identify and track each item individually** and efficiently update the UI when the list changes.
